# Dart Language Fundamentals

[![Dart](https://img.shields.io/badge/Dart-3.x-blue?style=for-the-badge&logo=dart)](https://dart.dev/)

## About The Project

This repository contains a collection of code examples and exercises created as a refresher on the Dart programming language. The main goal was to revisit and solidify core concepts before diving into mobile development with Flutter.

Each file focuses on a specific feature of the Dart language, serving as a practical reference.

## Topics Covered

The exercises in this repository cover a range of fundamental topics, including:

* Variables, Data Types, and Operators
* Control Flow (if/else, switch, loops)
* Functions and Parameters
* Null Safety
* Collections (Lists, Sets, Maps)
* Object-Oriented Programming (Classes, Constructors, Inheritance)
* Error Handling (try/catch)

## How to Use This Repository

All code examples are located in the `/bin` directory. Each `.dart` file is a self-contained script focused on a specific topic and can be executed individually.

To run a specific example from your terminal, use the Dart CLI:

```bash
# Example of running the first exercise
dart run bin/nome_do_arquivo.dart
```
